DiaComp: дневник диабетика

Учебный pet-проект на Java: дневник для людей с диабетом, в котором можно вести записи о состоянии и проходить обучение для новичков.

Статус:
В разработке. Текущая версия: v0.1 (консольный дневник, данные хранятся в памяти).

Идеи на будущее:
Распознавание еды по фото с оценкой углеводов (результат всегда подтверждает пользователь)
Калькулятор болюса по параметрам, которые задал врач
Напоминания об измерениях

Технологии:
Java 21
Maven
JUnit 5
(позже) Spring Boot, PostgreSQL, Docker

Структура проекта:
src/main/java/ru/diacomp/
├── diary/      # ядро: записи, сервис, интерфейс хранилища
├── storage/    # реализации хранилищ (память, файл, БД)
└── cli/        # консольный интерфейс
